# Support

## Getting Help

We're here to help! Here are the best ways to get support for Telegram Multi-Account Message Sender.

## Community channel (Discussions-first)

**Primary hub:** [GitHub Discussions](https://github.com/VoxHash/Telegram-Multi-Account-Message-Sender/discussions)

| Use Discussions for | Use Issues for |
| --- | --- |
| Questions, how-tos, setup help | Bugs with a clear repro |
| Feature ideas and product feedback | Tracked feature work |
| Sharing plugins, tips, and setups | Security reports → email (below) |
| Beta tester interest and early feedback | Actionable follow-ups from beta reports |

Starter threads:

- [Welcome — community hub](https://github.com/VoxHash/Telegram-Multi-Account-Message-Sender/discussions/1)
- [Beta testers: cloud backup & early features](https://github.com/VoxHash/Telegram-Multi-Account-Message-Sender/discussions/2)
- [Ask questions (Q&A)](https://github.com/VoxHash/Telegram-Multi-Account-Message-Sender/discussions/3)

**Discord:** There is no public Discord invite yet. When a server exists, this page will link it. Until then, use Discussions — do not rely on third-party Discord links claimed to be official.

**Beta tester list:** Prefer the [Beta Testers discussion](https://github.com/VoxHash/Telegram-Multi-Account-Message-Sender/discussions/2), or open a [Beta tester interest](.github/ISSUE_TEMPLATE/beta_tester.md) issue. Never paste session files, API keys, or tokens.

## Reporting Issues

Found a bug or have a feature request?

1. **Search existing issues** (and Discussions) to avoid duplicates
2. **Use the appropriate template**:
   - [Bug Report](.github/ISSUE_TEMPLATE/bug_report.md)
   - [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md)
   - [Documentation Improvement](.github/ISSUE_TEMPLATE/docs_improvement.md)
   - [Beta tester interest](.github/ISSUE_TEMPLATE/beta_tester.md)
   - [Plugin submission](.github/ISSUE_TEMPLATE/plugin_submission.md)

3. **Provide detailed information**:
   - Clear description of the issue
   - Steps to reproduce
   - Expected vs actual behavior
   - Environment details (OS, Python version, app version)
   - Relevant logs or error messages (redact secrets)

## Important Notes

- **Security Issues**: Please report security vulnerabilities via email (contact@voxhash.dev) rather than public issues — see [SECURITY.md](SECURITY.md)
- **API Issues**: For Telegram API-related issues, check [Telegram's documentation](https://core.telegram.org/api)
- **Rate Limiting**: Be aware of Telegram's rate limits and use the built-in rate limiting features
